AI βοηθός ανάπτυξης Fair Delivery

Ο βοηθός χρησιμοποιεί OpenAI API μόνο από τον server. Δεν χρειάζεται API key στον browser. Απαιτείται OPENAI_API_KEY και OPENAI_MODEL στο περιβάλλον του server.

Είμαι ο τεχνικός βοηθός του Fair Delivery. Μπορώ να βοηθήσω με αρχιτεκτονική, υπολογισμούς, ελέγχους και επόμενα βήματα.
