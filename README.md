# Fair Delivery — πιλοτικό σύστημα (τιμολόγηση v4)

## Πολιτική τιμολόγησης v4 — δοκιμαστική, όχι πραγματικές εισπράξεις

- **Χρέωση υπηρεσίας πελάτη 2,30 €** (μικτό, με υποθετικό ΦΠΑ υπηρεσίας 24%: 1,85 € έσοδο + 0,45 € ΦΠΑ). **Προμήθεια καταστήματος 8%** επί της εμφανιζόμενης αξίας προϊόντων (συμπεριλαμβάνει ΦΠΑ προϊόντων), **πλέον ΦΠΑ υπηρεσίας προμήθειας 24%**. Η εμπορική βάση προμήθειας και οι φορολογικοί συντελεστές απαιτούν έλεγχο λογιστή πριν την εμπορική λειτουργία.
- Ξεχωριστή χρέωση διανομής από το κατάστημα, ορατή στο καλάθι.
- Το κατάστημα μπορεί να κάνει παραδόσεις με δικούς του διανομείς χωρίς προσωπικό rider account, ή να δημιουργήσει προαιρετικούς προσωπικούς λογαριασμούς.
- Ο διαχειριστής εκδίδει νέο κωδικό καταστήματος και το κατάστημα επανεκδίδει κωδικό υπάρχοντος διανομέα. Οι νέοι κωδικοί φυλάσσονται ως hash και εμφανίζονται μία φορά.
- Προσθήκη προϊόντων, αλλαγή τιμών και διαθεσιμότητας από το Shop App.
- Μόνιμη βάση PostgreSQL με `DATABASE_URL` για το Render. Η έκδοση αρνείται να ξεκινήσει στο Render χωρίς βάση, ώστε ένα ακούσιο deployment να μην εμφανίσει άδεια δεδομένα. Τοπικά υποστηρίζεται JSON για δοκιμές.
- Χωρίς OpenAI API λειτουργεί ένας περιορισμένος οδηγός βοήθειας, **όχι πραγματικό AI**. Η σύνδεση πραγματικού AI απαιτεί ξεχωριστό API key και μπορεί να έχει κόστος.

Η έκδοση παραμένει **πιλοτική, χωρίς online πληρωμές**. Για εμπορική χρήση χρειάζονται λογιστικός, νομικός, τεχνικός έλεγχος, αντίγραφα ασφαλείας και πλήρεις λειτουργίες πληρωμών.

Αυτή η έκδοση αντικαθιστά το προβληματικό demo flow με μία κοινή, πρωτότυπη εφαρμογή Node.js για τοπική πιλοτική δοκιμή. Δεν αντιγράφει κώδικα, APK, ιδιωτικά endpoints ή μηχανισμούς της efood.

## Τι διορθώθηκε

- Ένα ενιαίο backend με πραγματικά endpoints `/api/...` αντί για τις λανθασμένες κλήσεις `https://onrender.com`.
- Κοινή ροή παραγγελίας: πελάτης → κατάστημα → διανομέας → παράδοση.
- Ξεχωριστές οθόνες πελάτη, καταστήματος, διανομέα και Control Center.
- Σταθεροί λογαριασμοί οδηγών με προσωπικό κωδικό που δημιουργεί το κατάστημα.
- Ανάθεση έτοιμης παραγγελίας από το κατάστημα σε συγκεκριμένο οδηγό.
- Checkout με στοιχεία επικοινωνίας και συντεταγμένες παράδοσης.
- Χάρτες Leaflet για επιλογή διεύθυνσης, κατάστημα, οδηγό και tracking.
- Επιβεβαίωση κατάστασης με έλεγχο επιτρεπτών μεταβάσεων.
- Δημιουργία παραγγελίας με τιμές προϊόντων που ελέγχονται στον server, όχι με τιμές που στέλνει ο browser.
- Τοπική αποθήκευση σε JSON με σειριοποιημένες εγγραφές και atomic rename.
- Σύνδεση shop/rider/admin με κωδικούς ρόλων και HttpOnly session cookie.
- Περιορισμός συχνότητας στις δημόσιες δοκιμαστικές παραγγελίες και στον AI βοηθό.
- Προαιρετικός AI βοηθός μέσω OpenAI Responses API. Το API key παραμένει αποκλειστικά στον server.
- Πραγματικά στατιστικά από τη βάση· δεν χρησιμοποιούνται ψεύτικοι μετρητές.
- Ρητή άδεια browser πριν από κοινοποίηση GPS από τον διανομέα.

## Γρήγορη τοπική εκκίνηση σε Linux Mint

Απαιτείται Node.js 20 ή νεότερο. Η μόνη npm εξάρτηση είναι ο οδηγός PostgreSQL `pg`.

```bash
cp .env.example .env
npm test
npm start
```

Άνοιξε:

- Control Center: http://localhost:3000/
- Πελάτης: http://localhost:3000/customer-app.html
- Κατάστημα: http://localhost:3000/shop-app.html
- Διανομέας: http://localhost:3000/Rider-App.html

Στην τοπική λειτουργία `DEMO_MODE=true`, ο κωδικός δοκιμής για shop και admin είναι `demo`. Το κατάστημα δημιουργεί κάθε διανομέα από το Shop App και του δίνει το προσωπικό ID και τον κωδικό που εμφανίζεται μία φορά. Ο διανομέας χρησιμοποιεί ξανά τα ίδια στοιχεία σε κάθε σύνδεση· η ανάθεση παραμένει συνδεδεμένη με τον λογαριασμό του.

Τα προϊόντα που εμφανίζονται αρχικά είναι σαφώς δοκιμαστικά. Άλλαξέ τα από το Shop App πριν από οποιαδήποτε παρουσίαση σε πραγματικούς πελάτες. Το checkout εμφανίζει προϊόντα, κόστος υπηρεσίας, κόστος διανομής του καταστήματος και συνολικό ποσό πριν από την καταχώριση.

## Αναβάθμιση υπάρχοντος πιλοτικού

Πριν από αλλαγή της υπηρεσίας, κράτησε αντίγραφο του υπάρχοντος `DATA_DIR/state.json` και ολοκλήρωσε τυχόν διαδρομές που έχουν ανατεθεί. Η 1.3.0 διαβάζει υπάρχοντα προϊόντα, παραγγελίες και λογαριασμούς. Αναβαθμίζει μία φορά την παλιά πιλοτική χρέωση υπηρεσίας σε 1,79 € και επαναφέρει την προμήθεια καταστημάτων στο 0%. Κάθε επανεκκίνηση απαιτεί νέα σύνδεση, καθώς οι συνεδρίες παραμένουν στη μνήμη.

**Δικλείδες ασφαλείας deployment:** Στο Render η 1.3.0 δεν ξεκινά εάν λείπει το `DATABASE_URL`. Εάν η βάση δεν περιέχει ακόμα εγγραφή του Fair Delivery και δεν έχει μεταφερθεί το παλιό `state.json`, επίσης δεν ξεκινά. Η επιλογή `ALLOW_EMPTY_PRODUCTION_STATE=true` επιτρέπει ρητά την αρχικοποίηση **εντελώς άδειου** πιλοτικού — μόνο όταν έχουν ήδη διασωθεί ή δεν χρειάζονται τα προηγούμενα δεδομένα. Μην την ενεργοποιήσεις για αναβάθμιση με υπάρχουσες παραγγελίες. Το Render Free έχει προσωρινό filesystem, επομένως η διατήρηση λογαριασμών δεν εγγυάται απλώς με τη σύνδεση μιας νέας, άδειας PostgreSQL.

Το GPS ξεκινά με επιλογή του διανομέα και άδεια browser. Μετά από ανανέωση, η διαθεσιμότητα και οι αναθέσεις επανέρχονται και το GPS περιμένει νέα επιλογή «Κοινοποίηση θέσης». Η έξοδος ή η μετάβαση offline καθαρίζει τη θέση από το tracking, όπως και η ολοκλήρωση ή ακύρωση της παραγγελίας. Οι γραμμές στους χάρτες συνδέουν σημεία και δεν αποτελούν οδική πλοήγηση.

## AI βοηθός

Ο AI βοηθός εμφανίζεται στο Control Center και λειτουργεί μόνο όταν έχουν οριστεί στον server:

- `OPENAI_API_KEY`
- `OPENAI_MODEL` (ένα model ID διαθέσιμο στο συγκεκριμένο API project)

Μην τοποθετήσεις ποτέ το API key σε HTML, JavaScript του browser, APK, Git ή δημόσιο αρχείο. Το API χρεώνεται ξεχωριστά από τη συνδρομή ChatGPT. Ρύθμισε budget/alerts στην πλατφόρμα API πριν το ενεργοποιήσεις.

Χωρίς το API key/μοντέλο ο βοηθός απαντά μόνο σε περιορισμένο σύνολο θεμάτων της εφαρμογής και επισημαίνει ρητά ότι δεν είναι μοντέλο AI.

## Render — προτεινόμενη ρύθμιση πιλοτικού

- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- `HOST=0.0.0.0`
- `DEMO_MODE=false`
- `DATABASE_URL` ως προστατευμένο environment variable με την **εσωτερική** διεύθυνση σύνδεσης της PostgreSQL. Πριν το προσθέσεις, κράτησε αντίγραφο της τρέχουσας κατάστασης γιατί η αλλαγή μπορεί να προκαλέσει deployment και το υπάρχον JSON στο Render Free είναι προσωρινό. Μη δημοσιεύεις το connection string. Η ήδη δημιουργημένη δωρεάν βάση έχει ημερομηνία λήξης· χρειάζεται σχέδιο μεταφοράς ή αναβάθμισης πριν λήξει.
- `DATA_DIR=/var/data` (μόνο αν έχεις προσθέσει Render Persistent Disk με mount path `/var/data`)
- Πρόσθεσε `SHOP_ACCESS_CODE` και `ADMIN_ACCESS_CODE` ως Environment Variables με μεγάλους, διαφορετικούς μυστικούς κωδικούς. Οι προσωπικοί λογαριασμοί οδηγών δημιουργούνται από το Shop App και έχουν ξεχωριστούς κωδικούς.
- Πρόσθεσε `OPENAI_API_KEY` και `OPENAI_MODEL` μόνο αν ενεργοποιήσεις τον AI βοηθό.

**Μη χρησιμοποιήσεις `DEMO_MODE=true` σε δημόσια υπηρεσία.** Το `.env` δεν πρέπει να ανέβει στο GitHub. Αν έχει εκτεθεί οποιοδήποτε κλειδί, κάνε ανάκληση/περιστροφή του.

## API

- `GET /api/health` — έλεγχος server
- `GET /api/config` — δημόσιες επιχειρηματικές ρυθμίσεις
- `GET /api/products` — ενεργά προϊόντα
- `POST /api/orders` — δημιουργία δοκιμαστικής παραγγελίας
- `GET /api/orders` — λίστα παραγγελιών για shop/rider/admin
- `GET /api/orders/:id` — δημόσιο tracking με τυχαίο UUID
- `PATCH /api/orders/:id` — ελεγχόμενη αλλαγή κατάστασης ανά ρόλο
- `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me`
- `GET /api/stats` — admin στατιστικά
- `PATCH /api/settings` — admin ρυθμίσεις
- `GET/POST /api/shop/riders` — δημιουργία και λίστα οδηγών καταστήματος.
- `POST /api/shop/location` — αποθήκευση σημείου καταστήματος.
- `GET /api/rider/profile`, `POST /api/rider/status`, `POST /api/rider/location`
- `POST /api/assistant` — admin AI assistant
- `POST /api/admin/shop-code` — δημιουργία νέου προσωπικού κωδικού καταστήματος από τον διαχειριστή
- `POST /api/shop/riders/:id/reset-code` — νέα στοιχεία πρόσβασης υπάρχοντος διανομέα
- `GET/POST /api/shop/products`, `PATCH /api/shop/products/:id` — διαχείριση μενού
- `POST /api/shop/delivery-fee` — κόστος διανομής από το κατάστημα

## Τι ΔΕΝ είναι ακόμη έτοιμο για εμπορική παραγωγή

Αυτή είναι λειτουργική τεχνική βάση single-store πιλοτικού, όχι ολοκληρωμένη εμπορική πλατφόρμα. Δεν περιλαμβάνει ακόμη:

- Πραγματικούς λογαριασμούς χρηστών, επαλήθευση email/τηλεφώνου, ανάκτηση κωδικού ή 2FA.
- Πολλαπλά καταστήματα με απομόνωση δεδομένων ανά κατάστημα και διαχείριση καταλόγων από UI.
- Πληρωμές, επιστροφές, τιμολόγηση, φορολογική/λογιστική ροή ή διασύνδεση PSP.
- Επίσημη/εξουσιοδοτημένη διασύνδεση με τρίτες πλατφόρμες.
- Πλήρη live route navigation, push notifications ή αξιόπιστο GPS στο παρασκήνιο.
- Η PostgreSQL πρέπει να συνδεθεί/επαληθευτεί χωριστά. Το JSON store είναι μόνο για τοπικές δοκιμές/single-instance pilot και δεν πρέπει να χρησιμοποιηθεί για πραγματικά δεδομένα στο Render Free. Για παραγωγή χρειάζονται backup, αξιόπιστες μεταναστεύσεις και έλεγχος ταυτόχρονων εγγραφών.
- Νομικό έλεγχο, GDPR διαδικασίες, όρους χρήσης, πολιτική απορρήτου, συμφωνίες καταστημάτων/διανομέων ή production security review.

Οι τιμές `2,30 €` χρέωση υπηρεσίας πελάτη (με ενδεικτικό ΦΠΑ 24%), `8%` προμήθεια επί προϊόντων (πλέον ΦΠΑ υπηρεσίας προμήθειας) και οι αμοιβές διανομέων είναι δοκιμαστικές παραδοχές, όχι πραγματικές εισπράξεις ή επιβεβαιωμένα φορολογικά παραστατικά. Η αρχική διανομή γίνεται από προσωπικό των καταστημάτων.

## Smoke test

Το `npm test` εκτελεί την πλήρη πιλοτική ροή και ελέγχους για προσωπικούς λογαριασμούς, ανάθεση σε έναν οδηγό, επανασύνδεση και επανεκκίνηση server, ξεχωριστές συνεδρίες ρόλων, απόκρυψη προσωπικών στοιχείων από το δημόσιο tracking, καθαρισμό GPS, έλεγχο δεδομένων και περιορισμό προσπαθειών σύνδεσης. Ελέγχει επίσης την επιλογή σωστού ρόλου ανά σελίδα όταν ο ίδιος browser έχει πολλά session cookies. Δεν ελέγχει πραγματικό deployment, πληρωμές ή εξωτερικό AI API.


## Μετάβαση τιμολόγησης v4 — 23/11/2026

- **Μόνο νέες παραγγελίες:** υπολογισμός χρεώσεων από server, immutable `pricingSnapshot`, `shop-percent-v2` με `shopFeeCents` για την προμήθεια 8% + ΦΠΑ υπηρεσίας.
- **Ιστορικές παραγγελίες:** `shop-fixed-v1` διατηρεί τη χρέωση 1 € που ίσχυε κατά τη δημιουργία της. Ούτε η οφειλή ούτε οι εγγραφές εκκαθάρισης επανυπολογίζονται αναδρομικά.
- **Παράδειγμα:** προϊόντα 20 €, μεταφορικά 0 €. Πελάτης: 22,30 €. Κατάστημα: προμήθεια 1,60 € + εκτιμώμενο ΦΠΑ υπηρεσίας 0,38 € = 1,98 €. Πλατφόρμα: έσοδο προ ΦΠΑ 1,85 € + 1,60 € = 3,45 € πριν κόστος πληρωμών, διανομής, υποδομών, επιστροφών, φόρους και εισφορές.
- **Admin dashboard:** χωριστές προβολές μικτών χρεώσεων, εκτιμώμενου ΦΠΑ υπηρεσιών και εσόδων προ ΦΠΑ. Αυτές είναι λογιστικές *προβολές πιλοτικού*, όχι εισπράξεις ή διαθέσιμα κέρδη.
- **Ενεργοποίηση:** δεν έχει συνδεθεί πάροχος πληρωμών ούτε έχουν ενεργοποιηθεί αληθινές χρεώσεις. Πριν από merge/deploy, έλεγξε παραγωγικό backup και σύνδεση PostgreSQL, νομική σύμβαση καταστημάτων και κανόνες ΦΠΑ με λογιστή. Η δωρεάν Render PostgreSQL έχει λήξη στις 16/12/2026: απαιτείται βιώσιμη βάση δεδομένων πριν εμπορική χρήση.
- **Ασφάλεια:** ξεχωριστό PR προς `fix/fair-delivery-pilot-1-3`, πλήρεις δοκιμές `npm test`; ο τρέχων κλάδος Render δεν αλλάζει έως έγκριση deployment.
